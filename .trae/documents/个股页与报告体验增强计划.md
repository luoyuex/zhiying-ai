# 个股页与报告体验增强计划

## Context

`docs/DEVELOPMENT_PLAN.md` 中 P3/P5 仍有三类缺口：个股页看不到指标叠加、资金流和资讯；报告页只有文字结论，没有 6 维评分概览、无法对比两次诊断、不能导出。本次一次性补齐，并把图表/资讯能力封装成可复用组件。

已确认的技术方向：
- K 线使用 **klinecharts**（9.8.12），替换个股页现有大图 MiniKline。
- PDF 使用**前端一键下载**。注意：`html2pdf.js` 内置 html2canvas 1.x 不支持 Tailwind 4 产出的 `oklch` / `color-mix` 颜色（已在 `frontend/dist` 构建产物中确认存在），因此改用 `html2canvas-pro@2` + `jspdf@4` 实现同样的「点按钮直接下载」体验。
- 资讯：东财公告 + 东财新闻（均免密钥，已实测可用）；元宝只在用户点「AI 检索资讯」时调用 1 次，缓存 6 小时。
- 报告对比：详情页「对比上一次」+ 历史页手动勾选两份，两种入口都做。
- 雷达图自研 SVG，不引入 ECharts。

## 一、后端

### 1. 新闻/公告
新增 `backend/app/schemas/news.py`：
- `NewsItem(id, kind, title, summary, url, source, published_at)`；`kind` 为 `announcement` / `article`
- `CompanyNewsData(symbol, announcements, articles, source, fetched_at, partial)`

新增 `backend/app/providers/news.py`（两个 Provider 共用解析与去重）：
- `EastmoneyAnnouncementProvider`：`np-anotice-stock.eastmoney.com/api/security/ann`，`page_size=20&ann_type=A&stock_list={code}`；`title`、`notice_date`、`columns`、`art_code`；URL 拼 `https://data.eastmoney.com/notices/detail/{code}/{art_code}.html`；Referer `https://data.eastmoney.com/`
- `EastmoneyNewsSearchProvider`：`search-api-web.eastmoney.com/search/jsonp`，`param` 为 JSON（`keyword={name} {code}`、`type=["cmsArticleWebOld"]`、`pageSize=20`）；剥离 `cb(` / `)` 后 `json.loads`，清理 `<em>`、`html.unescape`，按 URL/标题去重
- 均走 `providers/http.py::fetch` + `provider_slot`，超时沿用 `market_http_timeout`

新增 `backend/app/services/company_news_service.py`：
- `get_company_news(redis, symbol, name, limit=20)`：并发拉两源，Redis key `mkt:news:{code}`，TTL 新增配置 `market_news_cache_seconds=600`
- 单源失败 → `partial=true` 仍返回；双源失败 → `MarketUnavailable`；缓存损坏/Redis 异常放行

### 2. 资金流接口
- 小幅重构 `backend/app/providers/fundflow.py::get_fund_flow`：入参由 `Quote` 改为 `symbol: str`（内部 `parse_symbol`），调用点 `ai_job_service.py:360` 改为 `get_fund_flow(redis, quote.symbol)`；缓存 key、TTL 300s 不变
- 这样新接口不必先取报价

### 3. API
`backend/app/api/v1/stocks.py` 新增：
- `GET /stocks/{symbol}/fund-flow` → `FundFlowData`（30 天）；非法代码 422、无数据 404、源失败 503
- `GET /stocks/{symbol}/news?limit=20` → `CompanyNewsData`；报价取名称失败时用代码做关键词
- `POST /stocks/{symbol}/news/ai-search` → 复用 `search_symbol_web`，新增可选参数 `cache_seconds`（默认读配置；此接口传 21600）；按 `web:search:cooldown:{user_id}:{symbol}` `SET NX EX 30` 防连点，命中返回 `errors.rate_limited`；未配置元宝返回 `success=false` 的结果，不报 500

`backend/app/core/config.py` 新增：`market_news_cache_seconds=600`、`market_news_ai_cache_seconds=21600`（`.env.example` 同步）。

## 二、前端

### 1. 依赖
`frontend/package.json`：`klinecharts@9.8.12`、`html2canvas-pro@^2.5.2`、`jspdf@^4.0.0`。

### 2. 新增组件（按可复用原则拆）
- `components/market/KlineChart.vue`：props `bars / height?`；负责 init、数据映射（`YYYY-MM-DD` 按 `+08:00` 解析为 timestamp）、`applyNewData`、MA + BOLL 主图、VOL + MACD(12,26,9) 副图、`ResizeObserver` resize、卸载 dispose；`setStyles` 用 `utils/theme.ts::readToken()` 读出的具体色值（Canvas 读不到 CSS 变量）
- `components/market/FundFlowChart.vue`：纯 SVG，props `days / metric`；零轴对称柱、正红负绿、hover 显示数值
- `components/market/FundFlowSection.vue`：props `symbol`；内部取数，指标切换（主力/超大单/大单/中单/小单）、最新净额与净占比摘要、骨架/空态/错误重试；格式化复用 `utils/market.ts`
- `components/news/CompanyNewsPanel.vue`：props `symbol`；三个 tab「公告 / 新闻 / AI 资讯」；前两者进入即加载，AI 页签只在点按钮后请求并提示「缓存 6 小时」
- `components/report/AnalystRadar.vue`：props `series: { label, analysts }[]`（1 或 2 组）、`size?`；固定六轴 technical/fundamental/fund_flow/sentiment/risk/news，0–100；缺失维度画 0 并注明；中心显示均分；SVG 直接用 CSS 变量上色
- `pages/ReportComparePage.vue`：路由 `/reports/compare?ids=a,b`（必须注册在 `/reports/:id` 之前）；`Promise.all` 取两份详情，并排展示评级/置信度/时间、首席决策、关键价位、持仓建议、六维评分（雷达 + delta 表）、核心理由/风险、讨论轮次；旧报告缺字段时显示「—」
- `utils/theme.ts`：`readToken(name)`
- `utils/pdf.ts`：`exportElementToPdf(el, filename)`；html2canvas-pro `scale:2`、白底、`useCORS`，按 A4 切片写入 jsPDF，10mm 边距；失败时 `window.print()` 兜底

### 3. 复用与去重

### 4. 页面改造

## 五、风险

- klinecharts 9/10 API 不同：锁定 9.8.12，使用 `applyNewData`；容器必须有确定高度
- Canvas/SVG 无法读取 CSS 变量：统一经 `readToken()` 取具体色值
- 东财反爬：带 Referer/UA、走全局并发闸门、10 分钟缓存；单源失败不阻塞整页
- 东财新闻 JSONP：回调名、HTML 实体、`<em>` 标签需清洗；日期格式不统一
- html2canvas-pro 对长报告分页与内联 SVG 支持有限：先用真实报告验证，失败降级浏览器打印
- 旧报告可能缺 `position_action / position_advice / discussion`：对比页与详情页均做空值兜底
